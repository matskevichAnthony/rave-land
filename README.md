# Rave Land

Мир в браузере: рельеф из шума, персонаж с коллизиями, неон и встроенный редактор сцены.

## Запуск

Нужен Node 22.12 или новее: на нём стоит Vite 7, и со старой нодой запуск падает
невнятной ошибкой.

```sh
npm install
npm run dev
```

Страницы: `/` мир, `/understav.html` промо-сцена, `/toolbox.html` мастерская,
`/generator.html` генератор ассетов, `/status.html` статус проекта.

## Управление

Прогулка: клик по миру захватывает мышь (Esc отпускает), мышь вращает камеру,
колесо приближает. WASD ходьба, Shift бег, Space прыжок. Игрок сам является
персонажем мира, его внешность задаётся в `src/config.js` (`PLAYER.appearance`).

Клавиша 1 достаёт пистолет: клик стреляет по прицелу, убитый персонаж падает
физическим рэгдоллом и остаётся лежать. Без оружия клик по персонажу
открывает его карточку.

Tab открывает редактор:

- кнопки панели добавляют объекты в точку, куда смотрит камера;
- раздел «Из мастерской» показывает готовые модели с полигонажем и весом:
  пропы из Blender и прогоны генератора. Клик по карточке ставит модель в мир.
  Список берётся из той же описи `assets/inventory.json`, что и страница
  мастерской, поэтому свежий прогон появляется в редакторе после перезагрузки,
  без правок кода;
- клик по объекту выбирает его, клавиши 1/2/3 переключают режим гизмо
  (двигать, вращать, масштабировать), G прижимает к земле, X удаляет;
- параметры рельефа (сид, высота гор, радиус поляны) меняются на лету
  кнопкой «Пересоздать рельеф»;
- время суток (утро, день, ночь) переключается кнопками и сохраняется
  вместе с миром;
- «Сохранить» кладёт мир в localStorage, «Экспорт world.json» скачивает файл.
  Скачанный файл кладётся в `public/world.json` и становится стартовым миром.

## Персонажи

NPC живут в `world.json` в списке `npcs`: имя, архетип (raver, goth, stalker,
medic), сид внешности, домашняя точка и `data` с любыми ключ-значение. Они
блуждают по рельефу, над головой имя, клик открывает карточку с данными.

Вместо процедурного архетипа можно указать `src` с путём к GLB: модель из
Tripo/Meshy подхватится вместе со своими анимациями (клипы idle/walk/run
находятся по именам). Модель без анимаций (например, из TRELLIS) получает
простую кукольную анимацию: покачивание и подпрыгивание при ходьбе. Тяжёлые
генерации прогоняются через ретро-пасс перед добавлением:

```sh
npx @gltf-transform/cli weld in.glb tmp.glb
npx @gltf-transform/cli simplify tmp.glb tmp2.glb --ratio 0.04 --error 0.01
npx @gltf-transform/cli resize tmp2.glb out.glb --width 256 --height 256
```

Пайплайн генерации персонажей из набросков описан в `docs/npc-generation.md`.
Полностью локальный авториг T-pose моделей (скелет по лендмаркам, автовеса
через voxel-прокси, программные клипы Idle/Walk/Run) лежит скриптами в
`_other/auto-rig/`, страховочный путь через Mixamo: `_other/character-rigging/`.

Кнопка «Персонаж» в редакторе спавнит случайного гостя. Из консоли:
`raveland.addNpc({ name, archetype, seed, position: [x, null, z], data })`.

## Свои модели

GLB-файл перетаскивается прямо в окно и появляется в сцене. Чтобы модель
пережила перезагрузку, файл нужно положить в `public/assets/models/` с тем же
именем.

## Формат мира

`public/world.json` хранит параметры рельефа и список объектов с трансформами.
`y: null` в позиции означает «прижать к земле при загрузке».

Стартовая карта собрана только из готовых моделей: процедурные постройки
(домик, дерево, колонки, танцпол, фонарь, камень) из неё убраны, чтобы мир
состоял из тех же ассетов, что лежат в мастерской. Сами сборщики остались в
`src/objects/library.js` и доступны кнопками редактора, так что вернуть их в
мир можно кликом. Замер этой замены: вызовов отрисовки 439 → 359, источников
света 10 → 6, буферов геометрии в памяти 136 → 78.

## Промо-сцена UNDERSTAV

`understav.html` это отдельный мир на том же движке: разрушенный индустриальный
неф с розой-окном, алтарь с лайнапом и стометровый коридор перед ним. Событие
целиком лежит данными в `public/understav.json`: заголовок, тэглайн, лайнап,
дата, состав гостей и сид. Ни одной строки события в коде нет.

Пульт справа, прячется клавишей `H` и в снимаемый кадр не попадает:

- камера: Афиша, Петля, Спуск, Пролёт по коридору, Свободная, Прогулка;
- кадр: 1:1, 9:16, 16:9 и во всё окно. Это разные кадрирования, а не обрезка
  после: холст физически меняет размер, поэтому в вертикали видно ровно то,
  что попадёт в файл;
- сид восемью знаками hex, он же в адресе (`understav.html?seed=b7d3e1f2`), и
  тот же сид навсегда даёт тот же кадр;
- ручки постобработки: датамош, хроматика, след, растекание яркого, разрушение
  дальнего плана, свечение, зерно. Все они ведутся настоящей экранной скоростью
  камеры и глубиной сцены, а не подобраны числом;
- съёмка: «Снять» пишет отрезок в mp4 с холста, «Кадр» кладёт PNG;
- замер: кадров в секунду, худший кадр, вызовы отрисовки и треугольники против
  бюджета из `src/understav/palette.js`.

Прогулка поднимает физику и ставит игрока с оружием: WASD, Shift бег, Space
прыжок, клавиша 1 достаёт ствол, клик стреляет. «Позвать гостя» добавляет NPC из
списка моделей в данных события, «Перестрелка» включает бой между фракциями.
Ходьба, население и бой взяты из основного мира без второй копии логики.
