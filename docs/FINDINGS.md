# Findings — журнал фактов и решений

Единое место фиксации всего, что выяснено о пайплайне персонажей, анимаций и инструментов.
Правила ведения:

- Одна запись = один факт/дефект/решение. Формат: `F-NNN` + статус.
- Статусы: `OPEN` (требует действия), `CLOSED` (закрыто, указано чем), `INFO` (факт, действия не требует).
- Новые записи добавляются в конец своего раздела, номера не переиспользуются.
- Каждое закрытие — отдельным коммитом со ссылкой на номер (`F-012: closed by ...`).

## 1. Железо и локальная генерация

### F-001 · INFO · Целевая машина не тянет локальную 3D-генерацию
Локальная машина: Intel UHD Graphics G4 (без дискретной видеокарты), 7.6 ГБ RAM (~1.6 свободно), 2 ядра CPU.
Все актуальные image-to-3D модели (Hunyuan3D-2GP, Stable Fast 3D, TRELLIS) требуют минимум ~6 ГБ VRAM NVIDIA.
TripoSR официально НЕ поддерживает чистый CPU-инференс (вопреки распространённому мнению — CPU-fallback есть только у torchmcubes-компонента).
**Вердикт: локальная генерация на этой машине нежизнеспособна. Не тратить на неё время.**

### F-002 · CLOSED · Что машина реально тянет
Blender headless (риг, ретаргет, рендер контрольных кадров), gltf-transform/gltfpack постобработка — всё это уже успешно выполнялось на этой машине (пайплайны auto-rig и mocap/retarget). Рабочая схема: **генерация в облаке → всё остальное локально**.

### F-003 · INFO · _other/local-gen — тупиковая ветка
В `_other/local-gen/` остался только лог установки torch. Установку локальных весов не продолжать (см. F-001). Каталог оставлен как свидетельство попытки.

## 2. Лицензии

### F-004 · OPEN · Bandai-мокап блокирует коммерческий релиз
Все mocap-клипы в `character-animated.glb` (Walk + 3 вариации, Run, Dance, DanceLong) ретаргечены из датасета Bandai Namco Research — лицензия **CC BY-NC 4.0, коммерческое использование запрещено** (подтверждено: для коммерции нужно письменное разрешение Bandai Namco Research).
План замены при коммерциализации (по приоритету):
1. **Mesh2Motion** (mesh2motion.org) — 150+ анимаций, ассеты CC0, код MIT, работает в браузере без GPU.
2. **Quaternius Universal Animation Library** — CC0, включая коммерцию.
3. **CMU Motion Capture Database** — бесплатно включая коммерцию (нельзя перепродавать сами данные, нужна атрибуция); ретаргет через существующий `tools/anim/retarget.py` (добавить bone map для скелета CMU в `BONE_MAPS`).

### F-005 · INFO · Что уже чисто по лицензиям
Idle и Aim — самописные процедурные клипы (полностью наши). Меш персонажей — TRELLIS (MIT-код, открытые веса). Tripo free = CC BY 4.0 (по некоторым источникам free-тариф ограничен некоммерческим — проверять ToS перед коммерческим релизом), Meshy free = CC BY 4.0 с атрибуцией Meshy (коммерция разрешена).

## 3. Модели и клипы — текущее состояние

### F-006 · INFO · character-animated.glb — основной персонаж («Берлинец»)
`public/assets/models/character-animated.glb`, 1.5 МБ после постобработки, 17-костный риг, 9 клипов:
Idle (3.6с, процедурный), Aim (1.8с, процедурный), Walk (2.13с), WalkAngry (1.53с), WalkTired (4.87с), WalkFeminine (2.67с), Run (0.77с), Dance (6.67с), DanceLong (16.13с) — все mocap in-place, 30 fps, зациклены.
Имена подобраны под регулярки `src/npc/gltf-character.js`.

### F-007 · OPEN · bold-raver.glb — только процедурные клипы
`public/assets/models/bold-raver.glb` (1.26 МБ) заригован по стандартному пайплайну, но несёт только 5 процедурных клипов. Mocap на него не ретаргечен. Скрипт готов: `tools/anim/retarget.py` теперь принимает `--rig-dir` — достаточно указать `_other/bold-raver-rig` (нужен rig.blend, воспроизводится скриптами step1/step2 из исходного GLB, т.к. *.blend в git не хранится).

### F-008 · OPEN · dance-preview.glb — дубликат на удаление
`public/assets/models/dance-preview.glb` (2.8 МБ, сырой, без постобработки) дублирует клипы Dance/DanceLong из character-animated.glb. Используется только карточкой «Танцы» на /characters.html. Решение: перевести карточку на character-animated.glb и удалить файл (−2.8 МБ из public).

### F-009 · INFO · Известные дефекты клипов (принято, не чинится)
- Приблизительный поворот ладоней во всех mocap-клипах.
- Лёгкий футслайд на боковых шагах танца (нет IK-фиксации стоп).
- Умеренно согнутые локти в Run — стиль самого актёра (расслабленный джог), не дефект переноса.
На NPC-дистанции не читается. Чинить только если персонаж попадёт в кадр крупным планом.

### F-010 · CLOSED · Танец не проигрывался в игре
Код игры знал только idle/walk/run/aim, клипы Dance/DanceLong лежали мёртвым грузом.
**Закрыто:** `wander.js` получил состояние `dance` (NPC периодически танцуют на месте), `gltf-character.js` подбирает клип по `/dance/i`, `system.js` пробрасывает состояние.

### F-012 · INFO · Ключевая техника ретаргета (для будущих скелетов)
Скелет Bandai — «звезда» с костями вдоль ±X, вся поза в ротациях. Рабочее решение: перенос **абсолютных мировых ориентаций** с калибровкой по опорному кадру t0 (самая высокая стойка), а не дельт от rest-позы. Новые источники (CMU и т.п.) добавляются новым dict'ом в `BONE_MAPS` в `tools/anim/retarget.py`.
Грабли, уже пойманные: разворот на 180°, дубль первого кадра из-за молчаливого клэмпа импортёра BVH, «бег на пуантах» (лечится калибровкой питча стоп по кадру самой плоской опоры).

### F-013 · INFO · Mixamo-путь подготовлен, но не пройден
`_other/character-rigging/mixamo-ready.fbx` — меш с вшитыми текстурами, вердикт отчёта «READY FOR MIXAMO». Оставлен как страховка: если понадобится большая библиотека анимаций Mixamo (бесплатен с Adobe ID, только двуногие гуманоиды в нейтральной позе, официального API нет — только браузер).

### F-014 · INFO · Проверенный маршрут генерации
Единственный пройденный до конца маршрут: T-pose картинка → TRELLIS (HF Space) → локальный авториг Blender (17 костей) → процедурные/mocap клипы → postprocess.mjs (webp + квантизация). Оба игровых персонажа сделаны так.

### F-015 · OPEN · Облачные сервисы для следующих персонажей
Актуальные квоты и вердикты — в `docs/research/3d-services-2026.md`. Приоритет для этой машины: Tripo (200 кр/мес, API) → Meshy (100 кр/мес) → Hunyuan HF Space (бесплатная очередь, gradio_client) → TRELLIS Space (проверенный). Риг: свой авториг (проверен) → Mesh2Motion (CC0) → Mixamo (страховка).
