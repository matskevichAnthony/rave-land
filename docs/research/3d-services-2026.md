# 3D-сервисы и инструменты — проверенный каталог (август 2026)

Задача каталога: закрыть вопрос «откуда брать модели, риг и анимации» с учётом реальной машины
(без дискретной видеокарты, 7.6 ГБ RAM, 2 ядра — см. F-001 в `docs/FINDINGS.md`).
Пометки: ✅ проверено по источникам в августе 2026, ⚠️ требует проверки перед использованием.

## Главный вывод

Слабый ПК не должен выполнять генерацию. Рабочая схема, уже доказанная этим проектом:

```
картинка → облачная генерация (Tripo/Meshy/Hunyuan/TRELLIS Space)
        → локальный авториг Blender (проверен, 2 персонажа сделаны)
        → mocap-ретаргет tools/anim/retarget.py (проверен, 7 клипов сделано)
        → postprocess (webp + квантизация, 3 МБ → 1.5 МБ)
```

## 1. Image-to-3D генераторы (по приоритету для нас)

| Сервис | Бесплатно | Лицензия результата | Автоматизация | Вердикт |
|---|---|---|---|---|
| **Tripo** | ✅ 200–300 кр/мес (~8 моделей), не переносятся | ✅ CC BY 4.0; ⚠️ по ряду источников free-тариф — только некоммерческое, сверить ToS перед коммерцией | Официальный API, Python SDK, MCP | **Первый выбор**: единственный с полным циклом mesh+rig+анимации через API |
| **Meshy** | ✅ 100 кр/мес, не переносятся | ✅ CC BY 4.0, коммерция разрешена с атрибуцией Meshy | API на платном тарифе; free — только сайт | Второй выбор; козырь — библиотека 600+ движений |
| **Hunyuan3D Space (HF)** | ✅ бесплатная очередь | открытые веса | `gradio_client` — скриптуется | Лучший «безлимитный» вариант, но только меш без рига |
| **TRELLIS Space (HF)** | ✅ бесплатная очередь | MIT-код, открытые веса | `gradio_client`, очередь | **Проверен нами** — оба персонажа сделаны им |
| Rodin / Hyper3D | preview бесплатен, экспорт за кредиты | — | API и браузер | Лучшая геометрия, но экспорт платный — резерв |
| Autodesk Flow Studio | бесплатный уровень | ⚠️ | в основном браузер | Внутри — тот же TRELLIS 2; риг внутри инструмента невозможен |
| Krea 3D / 3D AI Studio / Magic3D | ежедневные units / стартовые кредиты | ⚠️ | браузер | Мелкие резервы, не строить на них процесс |
| Sloyd | бесплатный уровень | ⚠️ | API/SDK по тарифу | Только для low-poly пропсов (мебель, оружие), не персонажи |

**Локальные модели (TripoSR, Stable Fast 3D, Hunyuan3D-2GP, ComfyUI-TRELLIS2) — все требуют ~6 ГБ VRAM NVIDIA. На нашей машине не запускаются. Вопрос закрыт (F-001).**

| **Mesh2Motion** (mesh2motion.org) | ✅ MIT-код, ассеты CC0, работает в браузере без GPU | Основная замена Bandai-анимаций (F-004) + авториг гуманоидов/квадропедов/существ |

## 4. Минимальный пакет анимаций (цель)

Уже есть: Idle, Walk (+3 вариации), Run, Aim, Dance, DanceLong.
Не хватает для полного пакета: hit reaction, fall/death, interact/pickup, turn in place, cautious walk.
Источник: Mesh2Motion/Quaternius (CC0) — сразу чисто по лицензии.

## 5. Оптимизация (уже внедрено / цели)

Инструменты: Blender headless → `postprocess.mjs` (gltf-transform: webp, квантизация) — работает.
Опционально добавить: gltfpack (meshopt), KTX2-текстуры, glTF Validator в CI.

Бюджеты (PS1/PS2-вайб):

| Тип | Треугольники | Текстуры | GLB |
|---|---|---|---|
| Главный персонаж | 8–15 тыс. | 1×1024 или 2×512 | 3–8 МБ |
| Фоновый NPC | 2–5 тыс. | 256–512 | 0.7–3 МБ |

Текущие файлы уже в бюджете: character-animated.glb 1.5 МБ, bold-raver.glb 1.26 МБ.

## 6. Правила автоматизации

Порядок предпочтения: официальный API/MCP → HF Space через `gradio_client` → Playwright →
ручная пауза только на login/CAPTCHA. Браузерный агент не обходит CAPTCHA, лимиты кредитов
и ToS — некоммерческий статус проекта не отменяет Terms of Service.
