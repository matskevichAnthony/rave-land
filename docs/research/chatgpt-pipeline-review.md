# Критический разбор ответа ChatGPT о пайплайне «картинка → анимированный GLB»

Разбирался ответ ChatGPT с большими таблицами сервисов (облачные генераторы, open-source
модели, риггинг, mocap-источники, финальная оптимизация). Общий вердикт: **каркас ответа
верный, но он написан без учёта нашей машины и нашего уже работающего пайплайна** —
половина рекомендаций для нас либо неприменима, либо уже сделана лучше.

## Что подтверждено (проверено по источникам, август 2026)

- Tripo: 200–300 бесплатных кредитов/мес, официальный API/SDK/MCP — верно.
- Meshy: 100 кредитов/мес, CC BY 4.0 с атрибуцией — верно.
- Mesh2Motion: MIT-код, CC0-ассеты, работает в браузере — верно, это ключевая находка ответа.
- Mixamo: бесплатен с Adobe ID без Creative Cloud, только двуногие гуманоиды, API нет — верно.
- Anything World: REST API с free tier — верно (подтверждён endpoint `/animate-processed`).
- Bandai CC BY-NC 4.0, CMU «бесплатно включая коммерцию», Quaternius CC0 — верно.
- Hunyuan3D-2GP: минимум 6 ГБ VRAM с профилями offload 4/5 — верно.
- Общая философия «слабый ПК не должен выполнять весь пайплайн» — верно и уже доказана нами.

## Ошибки и завышенные обещания

1. **«TripoSR — лучший аварийный CPU-вариант» — неверно.** TripoSR официально не
   поддерживает чистый CPU-инференс: CPU-fallback есть только у torchmcubes, ядро модели
   ожидает CUDA. На нашей машине (Intel UHD, без CUDA) не запустится вообще.
2. **Раздел «Open-source для слабого ПК» неприменим к нам целиком.** Все строки таблицы
   («6 ГБ VRAM», «6–8 ГБ NVIDIA») предполагают дискретную NVIDIA. У нас её нет. Ответ сам
   это оговаривает одной строкой в конце раздела, но таблица создаёт ложное впечатление выбора.
3. **Лицензия Tripo подана без оговорки.** CC BY 4.0 формально разрешает коммерцию, но по
   ряду источников free-тариф Tripo ограничен некоммерческим использованием — перед
   коммерческим релизом сверять актуальный ToS, а не таблицу.
4. **Список из ~30 сервисов — шум.** Krea/Magic3D/3D AI Studio/Sloyd/Point-E/Shap-E/
   DreamGaussian и т.п. не дают ничего сверх топ-4 (Tripo, Meshy, Hunyuan, TRELLIS) и лишь
   размывают фокус. Роутер с fallback на 8 сервисов — оверинжиниринг для проекта, которому
   нужно несколько NPC.
5. **Игнорирует уже сделанное.** Ответ предлагает «Tripo/Meshy → Mixamo → Mesh2Motion» как
   путь рига, тогда как у нас уже есть проверенный локальный авториг (2 персонажа) и рабочий
   BVH-ретаргет с решённой задачей переноса мировых ориентаций — это дешевле и полностью
   под контролем. Внешний риг нужен только как страховка.
6. **Vision-оценка кандидатов + четыре ортографических вида** — разумная идея на будущее,
   но преждевременная: при 8 моделях/мес на Tripo дешевле выбрать глазами.

## Что берём из ответа (и уже зафиксировано)

- Mesh2Motion как замена Bandai-клипов для коммерции → F-004.
- CMU как коммерчески чистый mocap → F-004 (нужен bone map в retarget.py).
- Anything World API — на случай нечеловеческих существ.
- Бюджеты полигонов/текстур для PS1/PS2-вайба → `3d-services-2026.md`, раздел 5.
- gltfpack + KTX2 как следующий шаг оптимизации.
- Порядок автоматизации: API → gradio_client → Playwright, без обхода CAPTCHA/ToS.

## Что отбрасываем

- Всю локальную генерацию (F-001 закрывает вопрос).
- Мульти-сервисный роутер с vision-оценкой — до тех пор, пока не понадобится массовая
  генерация NPC.
- AccuRIG (desktop GUI), RigNet/UniRig/SkinTokens (CUDA) — несовместимы с машиной.
