## Когда звать

Когда прототипу нужно население, а не уникальный герой: 296 стоковых моделей
проходят импортёр без единого исключения, и анимации ложатся на них без
ретаргета. Это самый дешёвый способ наполнить мир людьми.

## Что помнить до запуска

- Лицензия. Ассеты Rockstar годятся для локального прототипа и не годятся для
  релиза. Всё, что импортировано, помечать в provenance как временное.
- Модель и её текстуры лежат порознь: `.dff` рядом с `.txd` того же имени.
  Оба достаются из `gta3.img` читателем `tools/gta/img.py`, распакованное
  держать во временной папке: в репозиторий исходники не едут.
- Клипы берутся из пакета анимаций именами, список смотреть чтением того же
  пакета, а не памятью.
- Пакеты оружия и танцев лежат внутри `anim.img`, тем же читателем: `ped.ifp`
  один боевого персонажа не делает (F-048).

## Правила прогона

- Флаг пакета анимаций повторяемый: несколько пакетов сразу дают персонажа,
  собранного из базовых поз и клипов оружия одновременно.
- Боец собирается по образцу, а не на глаз: набор клипов сверять с уже готовым
  `gta-cop.glb` (37 клипов, шесть пакетов), иначе персонаж окажется без стойки,
  стрейфа, прыжка и смерти (F-055).
- Свои смещения оружию не считать: кость кисти держит ствол единичной матрицей,
  так это устроено в самой игре.
- Постобработка встроена в скрипт, отдельно её гнать не нужно.

## После прогона

- Записать в мир и проверить в браузере. Старый сохранённый мир в localStorage
  перекрывает новый, его надо сбросить, иначе персонажа не будет видно.
- Клип, снятый с модели GTA, на нашего персонажа просто так не ляжет: rest-позы
  разные. Перенос идёт через общий маршрут BVH.
