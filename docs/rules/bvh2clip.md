## Когда звать

Единственный вход для любых новых анимаций. Ручных клипов не рисуем: своя
анимация годится только заглушкой, движение берём из мокапа.

## Что подготовить на входе

- Источник любой, лишь бы приводился к BVH. Свой формат превращает в BVH
  адаптер, писать надо его, а не второй ретаргет.
- Каталог рига обязателен: в нём лежит `rig.blend`, который делают шаги
  авторига. Без него ретаргет падает.
- Имя клипа выбирать по роли (`Walk`, `Run`, `Dance`), под этим именем его потом
  ищет аниматор.

## Правила прогона

- Клипы копятся в одном GLB: каждый прогон дописывает свой в файл персонажа.
  Поэтому `--out` указывать осознанно, иначе перезапишется основной персонаж.
- Отрезок берётся ключами `--start` и `--end`, лишние секунды в клип не тащить.
- Один персонаж это один каталог рига. Общее хранилище клипов подмешивает чужие
  позы, так уже ловили.
- Клип с чужой rest-позой на другого персонажа не переносится: скелеты
  совпадают, а позы покоя нет.

## После прогона

- Проверить глазами на странице персонажей: клипы там переключаются кнопками.
- Записать источник и лицензию мокапа в `provenance.animations`. Bandai это
  CC BY-NC, для релиза его придётся заменить, и это должно быть видно.
