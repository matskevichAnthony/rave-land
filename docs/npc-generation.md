# Персонажи для Rave Land: пайплайны генерации NPC

Актуально на июль 2026. Цель: получать риггованных лоу-поли персонажей с анимациями
в GLB, в эстетике ранних 3D-хорроров (Resident Evil 1, Cry of Fear): 300-800
треугольников, текстуры 64-128px с нарисованными лицами, мрачные приглушённые цвета.
Владелец не моделит, но рисует от руки и готов пользоваться AI-сервисами.

Приложение уже умеет принимать GLB drag-drop (см. README), файл кладётся в
`public/assets/models/`. Анимации внутри GLB сцена пока не проигрывает: для ходячих
NPC понадобится добавить `THREE.AnimationMixer` в код загрузки. Файлы при этом стоит
сразу готовить с анимационными клипами внутри, чтобы контент не переделывать.

## 1. AI-генерация персонажа из картинки или наброска

Общий принцип у всех сервисов: загружаешь картинку (или текстовый промпт), через
1-2 минуты получаешь текстурированный меш. Дальше у части сервисов есть авто-риггинг
и библиотека анимаций. Рукописный набросок лучше сначала прогнать через любой
генератор картинок (ChatGPT, Gemini, Recraft) с промптом вида "PS1 survival horror
character concept art, full body, T-pose, front view, muted colors" - чистый концепт
в T-позе генерится в 3D заметно лучше, чем сырой скетч.

### Tripo (tripo3d.ai) - главный кандидат

- Что: текст/картинка в 3D, авто-риггинг (люди, животные, стилизованные персонажи),
  пресеты анимаций (walk, run, idle и др.) с ретаргетом на свой риг, режим
  smart low-poly на выходе. Экспорт GLB, FBX, OBJ, USD.
- Цена: Free 300 кредитов/мес (только некоммерческое, до 15 скачиваний/мес).
  Pro $19.90/мес = 3000 кредитов (при годовой оплате ~$11.94/мес). Одна генерация
  с текстурой: порядка 25-40 кредитов, риггинг и анимация тратят кредиты отдельно.
- Пайплайн: набросок -> чистый концепт в T-позе -> Image to 3D -> включить
  риггинг -> навесить пресет-анимации -> экспорт GLB -> ретро-пасс (раздел 5).
- Подводные камни: меш триангулированный и "гладкий", сырой результат выглядит
  слишком современно - ретро-пасс обязателен. Свободные позы риггуются плохо,
  нужна T/A-поза. На Free модели публичные и некоммерческие.

### Meshy (meshy.ai)

- Что: то же самое, авто-риггинг за ~30 секунд, библиотека 500-600+ пресетов
  анимаций (на Free доступно ~20). Экспорт GLB, FBX, USDZ, BLEND.
- Цена: Free 100 кредитов/мес (ассеты публичные, лицензия CC BY 4.0).
  Pro $20/мес = 1000 кредитов, Max $60/мес.
- Пайплайн идентичен Tripo. У Meshy сильная сторона - объём библиотеки анимаций
  (танцы, бой, idle-вариации: для рейв-сцены танцы особенно кстати).
- Подводные камни: те же, что у Tripo. Кредитов на Free меньше, чем у Tripo.

### Hunyuan3D 3.5 (Tencent, hunyuan3d.ai / 3d.hunyuan.tencent.com)

- Что: генерация из текста/картинки/мультивью-фото, PBR-текстуры до 8K, геометрия
  очень детальная. Экспорт GLB, OBJ, FBX, STL. Версия 2.x открыта и запускается
  локально, 3.x/3.5 - облачный сервис (доступен и через реселлеров вроде
  3daistudio.com).
- Цена: у Tencent щедрый бесплатный лимит (ежедневные бесплатные генерации),
  дальше кредиты/подписка.
- Подводные камни: НЕТ авто-риггинга - только меш. Риг придётся делать в
  Mixamo/Tripo (туда можно загрузить чужой меш). Интерфейс частично китайский.
  Для лоу-поли перебор по детализации, но децимация решает.

### TRELLIS.2 (Microsoft, open source)

- Что: открытая (MIT) модель image-to-3D на 4B параметров, репо
  github.com/microsoft/TRELLIS.2, веса на Hugging Face (microsoft/TRELLIS.2-4B).
  Полные PBR-материалы, сложная топология, вышла в начале 2026.
- Цена: бесплатно, но нужен свой GPU (реально ~16+ GB VRAM) или аренда
  (RunPod/Vast, ~$0.3-0.7/час). Есть демо-спейсы на Hugging Face.
- Подводные камни: без риггинга, без анимаций, нужна возня с окружением Python.
  Это путь "для энтузиаста", не основной.

### Rodin / Hyper3D (hyper3d.ai)

- Что: Rodin Gen-2 (10B диффузионный трансформер), лучшее качество геометрии на
  рынке: чистая квад-топология, режим принудительной T/A-позы (сделан специально
  под последующий риггинг). Экспорт GLB, FBX, OBJ, USDZ + 4K PBR.
- Цена: Creator $30/мес, Business $120/мес, поштучно ~$1.5/кредит,
  генерация Gen-2 около 40 кредитов за скачивание - дорого.
- Подводные камни: авто-риггинг до сих пор "coming soon" (июль 2026), то есть риг
  отдельно через Mixamo/Tripo. Для PSX-стилизации переплата за качество, которое
  всё равно убьётся децимацией. Брать только если Tripo/Meshy не вытянули форму.

Вывод по разделу: полный цикл "картинка -> риггованный анимированный GLB" в 2026
закрывают только Tripo и Meshy. Остальные дают меш, риг нужен отдельно.

## 2. Риггинг и анимации отдельно

### Mixamo (mixamo.com)

- Жив, бесплатен (нужен Adobe-аккаунт), огромная библиотека анимаций, всё
  royalty-free для коммерции. Но Adobe не развивает сервис с 2015, в июне 2025
  лежал несколько дней, поддержка отвечала "not supported anymore". Работает,
  но закладываться на него навсегда не стоит.
- Workflow: загрузить меш (OBJ/FBX, гуманоид в T/A-позе) -> расставить маркеры
  (подбородок, запястья, локти, колени, пах) -> авто-риг ~2 мин -> выбрать
  анимации -> скачать FBX (with skin для первой, without skin для остальных).
- FBX -> GLB через Blender: File > Import > FBX, затем File > Export > glTF 2.0
  (формат glb, галка Animation). Несколько анимаций собираются в один GLB:
  импортировать все FBX на один риг (аддон Mixamo Rig с extensions.blender.org
  автоматизирует), в Nonlinear Animation убедиться, что каждый клип - отдельный
  NLA-трек, экспортнуть с включённым Group by NLA Track.
- Альтернатива без Blender: онлайн-конвертеры FBX->GLB теряют анимации через раз,
  надёжнее один раз поставить Blender ради конвертации (моделить в нём не нужно).

### Sorceress 3D Studio (sorceress.games)

- Браузерный авто-риг без Adobe ID, позиционируется как замена Mixamo. Молодой
  сервис, стоит проверить как запасной аэродром на случай смерти Mixamo.

### Авто-риггинг в AI-сервисах

- В Tripo и Meshy можно загрузить ЧУЖОЙ меш (GLB/FBX/OBJ) и получить риг + пресеты
  анимаций. Это удобный "Mixamo нового поколения": один интерфейс, экспорт сразу
  в GLB без Blender. Тратит кредиты.

### Cascadeur (cascadeur.com)

- Физически-корректная ручная анимация с AI-ассистом. Free-тариф есть, Indie
  $12/мес. Мощно, но для задачи "NPC ходит и танцует" избыточно: пресетов
  Mixamo/Meshy хватит. Записать в "когда-нибудь потом".

## 3. Ручной путь: Blockbench

- Что: бесплатный open-source редактор лоу-поли (blockbench.net), работает в
  браузере (web.blockbench.net) и как десктоп-приложение. Родился для Minecraft,
  но с версии 4.0 есть свободное меш-моделирование (вершины, не только кубы).
  Пиксельные текстуры рисуются прямо на модели встроенной рисовалкой. Риггинг
  через bones во вкладке Animate, покадровые анимации там же. Экспорт glTF/GLB
  сохраняет анимации.
- Цена: бесплатно полностью.
- Насколько реально за вечер без опыта: кубический персонаж в стиле
  Minecraft/Crossy Road - реально (туториалов масса, интерфейс самый дружелюбный
  из всех 3D-редакторов). Угловатый органический меш уровня Cry of Fear - уже
  навык, за вечер не выйдет. Зато Blockbench идеален как ДОРАБОТЧИК: открыть
  AI-шный GLB, перерисовать текстуру лица в пиксель-арте, подправить цвета.
- Скелетные анимации из Blockbench в GLB работают, но риг там примитивный
  (без весов на вершину при кубах); для ходьбы гуманоида проще прогнать
  blockbench-модель через Mixamo/Tripo.
- Crocotile 3D ($29.99, crocotile3d.com): тайловый редактор, экспорт в GLB, бонусы
  и скиннинг есть, но заточен под окружение (стены, комнаты в PSX-стиле), а не под
  персонажей. Для NPC не брать; пригодится, если захочется PSX-интерьеров.

## 4. Готовые паки как временный контент

Быстрый способ заселить мир сегодня, пока свой пайплайн не отлажен.

- Quaternius (quaternius.com) - CC0, всё бесплатно:
  - Universal Base Characters: гуманоиды с универсальным ригом под ретаргет,
    glTF/FBX.
  - Ultimate Modular Men Pack: 11 персонажей, 24 анимации, модульные части тел,
    FBX + GLB (есть и на poly.pizza).
- Kenney (kenney.nl) - CC0, паки персонажей и анимаций в GLB, стиль более
  мультяшный, под хоррор придётся перекрашивать текстуры в тёмное.
- poly.pizza - агрегатор CC0-моделей (Quaternius, Kenney и др.), удобный поиск,
  скачивание сразу в GLB.
- itch.io, тег psx (itch.io/game-assets/free/tag-psx, 900+ ассетов). Конкретные
  находки под хоррор:
  - "Characters PSX" от Elbolilloduro - бесплатные ретро-персонажи, самый близкий
    к Cry of Fear вайб.
  - "Low Poly Human Mesh" от Comp-3 Interactive - базовый человек на 402 треугольника,
    отличная болванка для Mixamo + своя текстура.
  - "PSX Dungeon - Modular Asset Pack" от Goblinatron - не персонажи, но мрачное
    окружение в тему.
  - Искать также по тегам psx + character, лицензию проверять на странице каждого
    пака (не всё CC0, часто "free for commercial use with credit").
- OpenGameArt.org: раздел LowPoly RPG Characters и поиск по "psx" - лицензии
  разные, смотреть внимательно.

Подводный камень: паки в T-позе без анимаций прогонять через Mixamo/Tripo; паки
с анимациями проверять, что клипы лежат внутри GLB, а не отдельными файлами.

## 5. Стилизация под PSX / Cry of Fear

AI-генерация выходит слишком гладкой и чистой. Ретро-пасс из двух частей:
упростить меш и испортить текстуры.

### Меш и текстуры одной командой (gltf-transform)

```sh
npm i -g @gltf-transform/cli

# посмотреть, что внутри: сколько треугольников, какие текстуры
gltf-transform inspect npc.glb

# склеить дублирующиеся вершины, затем ужать меш до ~25% треугольников
gltf-transform weld npc.glb npc-welded.glb
gltf-transform simplify npc-welded.glb npc-low.glb --ratio 0.25 --error 0.001

# даунрез всех текстур до 128px (или 64 для жёсткого ретро)
gltf-transform resize npc-low.glb npc-psx.glb --width 128 --height 128
```

`--ratio` подбирать по результату: для AI-меша на 30-50k треугольников до
300-800 нужен ratio 0.01-0.05, идти ступенями (0.25 -> 0.05) и смотреть глазами,
где ломается силуэт. simplify сохраняет скиннинг и анимации.

### Dithering и палитра (ImageMagick)

gltf-transform не умеет dithering, поэтому текстуры вынимаются, обрабатываются
и кладутся обратно:

```sh
# распаковать GLB в .gltf + отдельные PNG
gltf-transform copy npc-psx.glb unpacked/npc.gltf

# каждый PNG: даунрез + ограничение палитры + дизеринг
magick unpacked/texture.png -resize 128x128 -dither FloydSteinberg -colors 24 unpacked/texture.png

# собрать обратно в GLB
gltf-transform copy unpacked/npc.gltf npc-final.glb
```

`-colors 16..32` даёт характерную PS1-зернистость. Для мрачной гаммы Cry of Fear
добавить `-modulate 90,70,100` (темнее и приглушённее) до квантования цветов.

### Blender-путь (больше контроля)

Аддон PSX Retro Tools от Fawkek (fawkek.itch.io/psx-retro-tools, есть бесплатная
версия, под Blender 5.0+): децимация с триангуляцией в один клик, запекание всех
материалов в одну низкоресную текстуру с палитрой, дизеринг (Bayer,
Floyd-Steinberg, Atkinson), vertex lighting. Это самый аутентичный результат,
но требует освоить основы Blender.

### Текстуры через Retro Diffusion

retrodiffusion.ai - AI-генератор пиксель-арта с моделью RD Tile для бесшовных
текстур (кредитная система, есть бесплатные стартовые кредиты). Годится для
одежды/кожи/граффити, когда нужна текстура "нарисованная руками в 1998".
Готовые PSX-текстуры также: "Retro PSX Textures" от Marcis на itch.io.

### На стороне three.js

Чтобы пиксели текстур были жёсткими, а не замыленными, при загрузке модели
выставить `texture.magFilter = THREE.NearestFilter` (и `minFilter` в
`NearestFilter` или `NearestMipmapNearestFilter`). Без этого даже правильная
64px-текстура будет выглядеть как акварель.

## 6. Итоговая рекомендация

### Основной пайплайн: набросок -> Tripo -> ретро-пасс

1. Нарисовать персонажа от руки, сфотографировать.
2. Прогнать через генератор картинок в чистый концепт: full body, T-pose,
   front view, muted horror palette (5 минут).
3. Tripo: Image to 3D -> авто-риггинг -> пресеты анимаций (idle, walk, dance) ->
   экспорт GLB (15-30 минут вместе с перегенерациями).
4. Ретро-пасс: gltf-transform simplify + resize, ImageMagick dithering (10 минут
   по готовым командам из раздела 5).
5. Drag-drop GLB в Rave Land, файл в `public/assets/models/`.

Оценка: первый персонаж за вечер (2-3 часа с освоением), дальше 30-60 минут на
персонажа. Деньги: попробовать бесплатно (300 кредитов Tripo хватит на 2-4
полных персонажа), для потока и коммерческих прав Tripo Pro $19.90/мес (годовая
~$12/мес). ImageMagick и gltf-transform бесплатны.

### Запасной 1: Meshy вместо Tripo

Тот же процесс, $20/мес, козырь - сотни пресетов анимаций (танцы для рейва).
Держать как второй сервис: генерации у них разные, что не вышло в одном, часто
выходит в другом.

### Запасной 2: готовые паки + Mixamo

Сегодня и бесплатно: Quaternius Universal Base Characters или "Characters PSX"
c itch.io -> при необходимости риг и анимации в Mixamo -> Blender FBX->GLB ->
ретро-пасс. Денег 0, времени 1-2 часа на первый проход (в основном на возню с
Blender-экспортом). Качество стиля у Elbolilloduro сразу "то самое", но
персонажи не твои авторские.

## Что проверить руками

1. Tripo бесплатно: скан наброска -> концепт в T-позе -> Image to 3D с ригом и
   walk-анимацией -> GLB -> перетащить в Rave Land. Проверяет весь основной
   пайплайн за один вечер, кроме проигрывания анимаций.
2. Ретро-пасс из раздела 5 на любом готовом GLB: подобрать рабочие значения
   --ratio и -colors, глядя на результат в мире. Эти же команды потом станут
   скриптом `npm run npc:retro`.
3. Скачать "Characters PSX" (Elbolilloduro, itch.io) и Universal Base Characters
   (Quaternius): бросить в мир, оценить, какой полигонаж и размер текстур
   реально смотрится в сцене, зафиксировать целевые цифры.
4. Добавить в загрузчик моделей AnimationMixer + NearestFilter для текстур:
   без этого ходячих NPC не будет, а пиксельные текстуры будут мылиться.
5. Blockbench за вечер: открыть AI-шный GLB и перерисовать текстуру лица
   в пиксель-арте. Дешёвый способ добавить "нарисованность" Cry of Fear поверх
   AI-генерации.
