# Авто-риг bold-raver: отчёт

## Итог

Персонаж из `~/Downloads/bold-raver.glb` (TRELLIS, 77 МБ, лысый парень в
techwear-жилете с портупеей, чистая T-pose) прогнан через пайплайн из
`_other/auto-rig/`: 17 костей, пять клипов (Idle, Walk, Run, Aim, Dance),
итог `character-final.glb` **1.26 МБ** (32 000 треугольников, webp-текстуры,
квантизация). Копия — `public/assets/models/bold-raver.glb`, карточка
«Bold Raver» добавлена в `src/characters-viewer/main.js`.

## Прогон

Библиотеки `rig_lib.py` / `anim_lib.py` переиспользованы из `auto-rig/` через
`sys.path.insert`, ничего в референсной папке не менялось. Степ-скрипты с
путями на эту папку лежат здесь.

1. `step1_rig.py`: импорт (919 691 вершина, 1 499 876 треугольников — в ~5 раз
   тяжелее референса), нормализация к росту 1.75 / подошвы в Z=0, лендмарки,
   арматура. Детект промежности упёрся в нижний клэмп (0.38 h): свободные
   штаны соединяют ноги ниже реальной промежности — клэмп отработал как
   задуман, правок не потребовалось.
2. `diag_render.py`: скелет поверх меша, front + side (`diag_front.png`,
   `diag_side.png`). Все кости внутри тела, наружу выглядывают только кончики
   кистей, носки ботинок и шея в открытом вороте — норма.
3. `step2_weights.py`: voxel-прокси 0.02 м (7 786 вершин), автовеса, Data
   Transfer POLYINTERP_NEAREST, normalize + limit 4 + clean.
4. `step2b_fix_unweighted.py` — **отличие от референса**: после трансфера
   осталось 2 919 невзвешенных вершин из 919 691 (у референса было 0) —
   внутренняя геометрия рта/челюсти (Z 1.48–1.53), которую водонепроницаемый
   прокси замуровал. Такие вершины в three.js схлопываются в начало координат,
   поэтому им присвоен вес 1.0 ближайшей кости (655 → neck, 2 264 → head).
   Итог: 0 невзвешенных.
5. `step3_anim.py`: пять клипов из `anim_lib.build_all` (forward = -1.0 из
   лендмарков), децимация 1 499 876 → 32 000 треугольников, экспорт GLB,
   превью поз (`idle/walk/run/aim/dance*.png`).
6. Пост-обработка: `node auto-rig/postprocess.mjs` с путями на эту папку
   (node_modules из `auto-rig/`). 32.3 МБ → 1.26 МБ. `prune` удалил один
   скин-дубликат; в итоге 1 скин, JOINTS_0/WEIGHTS_0 на месте, 3 webp-текстуры.
7. `verify_glb.py`: рендеры середины каждого клипа из готового GLB
   (`final-*-front/side.png`) — скиннинг пережил децимацию и квантизацию.

## Что видно на рендерах

- Idle: руки опущены вдоль тела, кисти у бёдер, поза живая.
- Walk/Run: шаг и бег читаются, в Run корпус наклонён, локти согнуты.
- Aim: правая рука строго горизонтально вперёд, левая поддерживает у
  запястья, ноги в стойке.
- Dance: кулаки у груди, колени согнуты в присед.
- Меш нигде не рвётся, руки не вывернуты, веса не плывут.
- На декимированном меше заметен тёмный «крап» по текстуре (UV-швы после
  collapse-децимации); на референсном тёмном персонаже это было незаметно,
  здесь на коже видно вблизи, на дистанции NPC — нет.

## Правки относительно референсного прогона

- Лендмарки: правок клэмпов не потребовалось — геометрия стандартная
  (T-pose, симметрия, без капюшона на голове).
- Единственное добавление — `step2b_fix_unweighted.py` (ближайшая кость для
  вершин, пропущенных weight transfer).
