# Авто-риг TRELLIS-персонажа: отчёт

## Итог

Полностью локальный риг + анимации. Персонаж (парень в тёмном techwear
с капюшоном) заригован 17 костями, имеет пять зацикленных in-place клипов
(Idle, Walk, Run, Aim, Dance) и ужат с 14.1 МБ до 1.22 МБ (32 000
треугольников, текстуры 512/256 webp, квантизация геометрии).

## Пайплайн

1. **Blender**: sudo без пароля недоступен, apt отпал — использована портативная
   сборка `blender-4.2.9-linux-x64` (лежит в этой папке), полностью user-space.
2. **Импорт и нормализация** (`step1_rig.py` + `rig_lib.py`): join мешей,
   apply transforms, масштаб к росту 1.75 м, origin в подошвы по центру.
3. **Лендмарки из геометрии** (numpy по вершинам): верх головы, плечевой пояс
   (медиана Z рукавных вершин), запястья/кисти (крайние X), промежность
   (минимум Z центральной колонки, с клэмпом), колени/лодыжки (медианы по
   срезам), направление «вперёд» из выступа носков стоп. Результат —
   `landmarks.json`.
4. **Скелет**: hips - spine - chest - neck - head + upper_arm/forearm/hand.L/R
   + thigh/shin/foot.L/R = 17 костей, симметрия L/R зеркалом.
5. **Веса**: `parent_set(ARMATURE_AUTO)` на исходном меше упал полностью
   (Bone Heat failed, 0 вершин с весами — несвязные оболочки AI-меша).
   Рабочий обход (`step2_weights.py`): voxel remesh копия (0.02 м, 8 204
   вершины, водонепроницаемая) → автовеса на ней прошли без ошибок → Data
   Transfer (POLYINTERP_NEAREST) весов на оригинал → normalize + limit 4 +
   clean. 0 невзвешенных вершин из 195 327.
6. **Анимации** (`step3_anim.py` + `anim_lib.py`): синусоидные кейфреймы каждые
   2 кадра, 30 fps. Ротации задаются в мировых осях и конвертируются в локальные
   кватернионы через инверсию rest-матрицы кости, без возни с bone roll.
   Точные позы (Aim, кулаки в Dance) делает `aim_quat`: наведение
   rest-направления кости на мировой вектор с точной компенсацией накопленного
   кватерниона родителей (child_world = W_parent @ W_child @ rest).
   - `Idle`, 108 кадров (3.6 с): руки опущены вдоль тела (86° от rest,
     ~77° ниже горизонтали T-pose), локти слегка согнуты, дыхание грудью,
     перенос веса с ноги на ногу (крен таза + попеременный сгиб коленей),
     редкий поворот головы (sin^3: взгляд «изредка», не маятник).
   - `Walk`, 32 кадра (1.07 с): бёдра ±27° в противофазе, колено до ~48°
     (флексия только назад), руки опущены (80°), мах ±25°, боб таза,
     контр-ротация корпуса, наклон 5°.
   - `Run`, 22 кадра (0.73 с): бёдра ±42°, колено до ~82°, локти согнуты
     сильнее (72°+), руки подняты до 62°, мах ±33°, наклон корпуса 13°.
   - `Aim`, 54 кадра (1.8 с): корпус развёрнут на 18°, правая рука выведена
     строго горизонтально вперёд (по -Y), лёгкий сгиб локтя, левая
     поддерживает у запястья (двуручный хват), ноги в лёгкой стойке,
     едва заметное дыхание и покачивание ствола.
   - `Dance`, 72 кадра (2.4 с): четыре пружинящих приседа за луп, качание
     бёдер на полтемпа, согнутые руки качают кулаками у груди, кивки головой.
   Все клипы in-place (hips смещается только по вертикали), уложены в
   NLA-треки, экспорт `export_animation_mode='NLA_TRACKS'`.
7. **Децимация**: Decimate (collapse) 279 197 -> 32 000 треугольников,
   применяется деструктивно в step3 перед экспортом (rig.blend на диске не
   меняется). Живой модификатор в стеке пересчитывался бы на каждом
   сэмплируемом кадре анимации и вешал экспорт. Веса переживают децимацию.
8. **Пост-обработка** (`postprocess.mjs`, запуск `npm install && npm run
   postprocess`): resample + dedup + prune, baseColor 512 webp,
   metallicRoughness 256 webp, quantize (KHR_mesh_quantization; позиции 14
   бит, нормали 8, UV 12). Без draco/meshopt, в приложении нет декодеров;
   webp и квантизацию three.js GLTFLoader читает нативно.
9. **Итог**: `character-final.glb` 1.22 МБ (36 607 вершин, текстуры 44 КБ +
   206 Б, анимации ~52 КБ), копия в
   `public/assets/models/character-animated.glb`. `gltf-transform inspect`
   подтверждает 5 анимаций по 51 каналу: Idle (3.6 c), Walk (1.07 c),
   Run (0.73 c), Aim (1.8 c), Dance (2.4 c).

## Визуальные итерации (Cycles-превью)

- **Итерация 1** (`idle2/walk2/run2/aim/dance*.png`): Idle починился, руки
  висят вдоль тела, кисти у бёдер, поза живая. Aim сломан: обе руки согнуты
  у груди «боксёром». Причина: `Bone.vector` не в координатах арматуры,
  rest-направление для наведения бралось неверно.
- **Итерация 2**: `aim_quat` переведён на `matrix_local`, компенсация
  родителей сделана точной (аккумулируются именно кейфреймленные
  кватернионы). Диагностика `debug_aim.py`: правая рука (0, -1, 0), строго
  вперёд. Кулаки в Dance переведены с elbow-сгиба (уходили вперёд, в фас
  скрадывались) на наведение к груди. Принято.
- **Финальная проверка** (`final-*-front/side.png`, `verify_glb.py`):
  рендеры из готового `character-final.glb` после децимации и квантизации.
  Скиннинг цел, веса не поплыли, все пять поз читаются.

## Тест в мире

Прежний экспорт проверен в мире Rave Land: сборка `npm run build`, preview,
headless chromium, `window.raveland.addNpc(...)`. Скриншоты
`world_shot1.png` / `world_shot2.png`: NPC анимируется, приложение само
проигрывает клипы. Формат нового файла тот же (GLB, webp-текстуры, те же
имена нод), плюс KHR_mesh_quantization, который GLTFLoader читает нативно.

## Границы подхода

- Веса с voxel-прокси «объёмные»: слои одежды двигаются вместе с телом одним
  куском. Для куртки поверх торса это плюс (нет разрывов), но вторичной
  динамики ткани нет.
- Плечи куртки в фас слегка «дутые» при опущенных руках (жёсткая привязка
  плечевой зоны рукава к chest); на дистанции NPC незаметно.
- Кисти: одна кость, пальцы не анимируются, хват в Aim условный.
- Лендмарки заточены под гуманоида в T/A-pose с симметрией; на нестандартных
  пропорциях (юбки, широкие силуэты) детект промежности/плеч потребует правок
  клэмпов.
